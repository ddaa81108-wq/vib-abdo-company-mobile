# تجهيز Firebase لصوت الإشعار — خطوات علي

لا تضع الملفات في الشات ولا في GitHub. التطبيق يشتغل بدونها، وصوت «التطبيق مقفول» يبقى مطفأ حتى تصل الملفات بالطريقة الآتية.

معرّف التطبيق على أندرويد: `com.vip2100.vib`

بصمة SHA-256 للشهادة، إن طلبتها وحدة التحكم:

`67b759d9346224742be950b4d700df58e48ceb9fd23646b4b6f7eb4f5be485ca`

## 1. مشروع Firebase

1. افتح [Firebase console](https://console.firebase.google.com/) بحسابك.
2. أضف مشروعًا جديدًا. الاسم أي اسم تعرفه، مثل `vib-abdo`.
3. يمكن إيقاف Analytics. لا يلزم للدفع.
4. من إعدادات المشروع، تأكد أن Cloud Messaging API (HTTP v1) مفعّل. المشاريع الجديدة تفعّله وحدها.

## 2. تطبيق أندرويد

1. أضف تطبيق Android.
2. اسم الحزمة: `com.vip2100.vib` بالحروف كما هي.
3. إن ظهر حقل SHA-256، الصق البصمة أعلاه. إن لم يظهر، أضفه لاحقًا من إعدادات التطبيق.
4. حمّل `google-services.json`. لا ترسله هنا.

## 3. مفتاح الإرسال للخادم

1. من إعدادات المشروع: حسابات الخدمة / Service accounts.
2. أنشئ مفتاحًا خاصًا (Generate new private key). الملف JSON.
3. هذا الملف سر. لا يُرفع إلى GitHub ولا يُلصق في رسالة.

## 4. التسليم

- `google-services.json`: يُحفظ كسر GitHub Actions بالاسم `GOOGLE_SERVICES_JSON_BASE64` (ترميز base64 للملف). فحص الإصدار يفكّه وقت البناء فقط، ويحذف الملف إن لم تكن الحزمة `com.vip2100.vib`. لا يُضاف إلى المستودع.
- ملف حساب الخدمة: يوضع على الخادم خارج المستودع، والمسار في المتغير `ABDO_FCM_SERVICE_ACCOUNT_FILE`. إن غاب الملف، الخادم لا يتصل بـ Google.

بعد التسليم يُبنى التطبيق بملف العميل، ويُعاد تشغيل الخادم بالمتغير. لا حاجة لتغيير الكود مرة أخرى.
