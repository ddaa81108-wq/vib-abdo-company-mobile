# مصفوفة الصلاحيات للتنفيذ والقبول

المرجع: القسم 4 من تحليل المشروع، مطبَّق على ملفات Fake API في `packages/api_layer/lib/data/fake/fake_fixtures.dart`.

الأدوار في هذه المصفوفة:

| العمود | التعريف في Fake API |
|---|---|
| مدير كامل | اسم يدخل ببادئة `admin` وليس `limited.admin` ولا `flag.admin`. الدور `admin`، القائمتان فارغتان، بلا علم `fullAccess`، فيصبح `fullAccess` عبر علم الدور |
| إداري محدود | بادئة `limited.admin`. الدور `admin` مع `collections.read` و`collections.write` و`collections.decide` و`debts.read` و`customerDebts: read` |
| موظف استلام | أي اسم آخر (مثل `employee…`). الدور `employee` مع `collections.read` و`collections.write` و`debts.read` و`customerDebts: read` وبقية `sectionAccess = none` |
| دور غير معروف | بادئة `guest` أو أي قيمة دور غير `admin` و`employee` بحرفيتها. الواجهة لا تمنح شيئًا ولو أُرسلت أكواد |

قيم الخلايا: **مسموح** (التحكم ظاهر ويعمل من جهة الواجهة)، **مخفي** (التحكم أو القسم غير مرسوم)، **قراءة** (القسم يُفتح بلا أزرار كتابة)، **بلا واجهة** (الدالة في المستودع فقط).

عمود **Fake الآن** نتيجة جولات القبول، وحدّث على `main` `8a52160` في القسم 6. عمود **Staging** كله `Not run`: لا مضيف staging ولا حسابات اختبار في هذه الجولة. الوضع الحقيقي بلا `API_BASE` يفشل مغلقًا، ولا مضيف بديل.

علم إضافي ليس عمود دور: `flag.admin` دور `admin` مع `fullAccess: false` وقوائم فارغة. الواجهة لا تمنح شيئًا. صفوفه في الاختبارات السلبية.

## 5. قراءة سريعة للنتيجة

الواجهة على Fake API تطابق أعمدة القسم 4 للإخفاء والإظهار في الملفات الأربعة. على PR #17 صار رفض الموظف لكتابة الكروت وقراءة الخزينة، ورفض الضيف لقراءة العملاء، 403 (DEF-006: Verified). على `c4edd59` صار `GET /api/home` يخفي القسم غير المقروء عن الضيف و`flag.admin` والموظف والمحدود، بما فيه الخزينة. الحمولة لا تعرض الشركات ولا الأمانات الليبية ولا المصراوية ولا المشتريات حتى للمدير. على #26 عند `589d645` اجتمع #17 و#24 وPR #3 ثم إقفال اليوم وملخص الرئيسية المخزَّن: السداد والقائمة والرئيسية 10315، ومنع `requestId`، وخزينة الموظف 403، ورفض غير المربوط ونقده ظاهران للمدير (DEF-007: Verified)، وإقفال اليوم يفحص الإصدار ويخزّن `b_2`. رفض الإداري المحدود متسق مع الزر ويبقى DEF-002: Pending PM decision. Staging غير مُختبَر بالكامل. #25 فرع منفصل، واشتراط كتابة القسم مع `debts.zero_review` سؤال مفتوح وليس عيبًا.
